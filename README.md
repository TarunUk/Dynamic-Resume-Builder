# 📄 Dynamic Resume Builder

A step-by-step resume builder built with **ASP.NET Core MVC + C# + Bootstrap 5** featuring live preview and 8 professional templates.

🌐 **Live Demo:** [https://dynamic-resume-builder-nqoa.onrender.com](https://dynamic-resume-builder-nqoa.onrender.com)

---

## ✨ Features

- 🪄 **8-Step Guided Form** — Personal Info, Experience, Education, Skills, Projects, Certifications, Languages, Template
- 👁️ **Live Preview** — Resume updates in real-time as you type
- 🎨 **8 Professional Templates** — Modern, Blue, Creative, Executive, Minimal, Academic, Bold, Elegant
- 📸 **Profile Photo Upload** — Drag & drop with Base64 encoding
- 💾 **Session Persistence** — Data saved across all steps
- 🏷️ **Skill Tags** — Tag-based input with suggested skills

## 🚀 Run Locally

```bash
git clone https://github.com/yourusername/ResumeBuilder.git
cd ResumeBuilder
dotnet run
```
Or open in **Visual Studio 2022** and press `Ctrl + F5`.

---

## 🔄 How It Works

```
Landing Page → Step 1 (Personal) → Step 2 (Experience) → Step 3 (Education)
→ Step 4 (Skills) → Step 5 (Projects) → Step 6 (Certifications)
→ Step 7 (Languages) → Step 8 (Template) → Preview
```

Each step saves to session. Left panel = form, Right panel = live preview.
